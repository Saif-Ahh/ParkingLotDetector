# ParkingLotDetector

A computer vision project to detect and analyze parking lots from images or video. Detects empty and occupied parking spots, counts available spaces, and provides basic metrics.

---

## 🚀 Features
- Detect parking lot layout and individual parking spots using OpenCV  
- Classify spots as empty or occupied  
- Count available vs total spots in an image or video frame  
- Output metrics (e.g. % occupancy)  

---

## 🛠️ Tech Stack
- **Languages:** Python  
- **Libraries:** OpenCV, NumPy  
- **Tools:** Git, possibly others for visualization / video processing
